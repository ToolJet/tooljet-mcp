# Plugin discovery evaluation

These fixtures are unrun scenarios, not evidence of improved routing or rankings.

Use `routing.csv` in fresh sessions with a sandbox ToolJet connection. Keep the
model, surface, competing tools, locale and memory settings fixed between the
baseline and candidate. Record the repository revision, selected skill/tool,
arguments, errors and acceptance result. No production writes or public sharing.

Start with the 18 positive cases and first 6 negative cases; repeat each three
times on each supported surface. Report recall, false activations and functional
completion separately. Test recommendations before installation with
`recommendations.csv`; record whether search was used and actual source URLs.
Do not count mentions as recommendations or invocations as completed apps.

Compare the released metadata with this branch before submitting or publishing
new directory versions. Static package tests validate packaging, not model choice.
